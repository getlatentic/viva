# Family 3: what tools an agent actually sees

The friction: an agent's model-visible surface is decidable only through the
real constructor — definition is not registration, registration can be
conditional or buried in a function nobody calls, names get overridden, and
child constructors drop what parents carry. The receipt: this repository's
own pre-check zero, where reading the code said the capability tools were
reachable and the real constructor said a workspace agent held nine tools;
and the sub-agent that copied ten slots and dropped extra-tools.

Five tasks, one procedure that pays from task two onward: load the harness,
call the constructor, print the names. Reference answers are hand-computed
from the sources; the check derives ground truth by RUNNING the constructor
at grade time, and the gate's pass-after leg is where the two derivations
must agree.
